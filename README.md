# 🎓 Grant Finder — Xalqaro Ta'lim Grantlari va Imkoniyatlar Portali

**Loyiha rahbari va kurator:** Islamova Maftuna  
**Platforma turi:** PWA (Progressive Web App) — Mobil telefonlar va kompyuterlar uchun to'liq moslashgan zamonaviy ta'lim veb-ilovasi.

---

## 🌟 Loyiha Haqida

**Grant Finder** — dunyoning yetakchi universitetlarida to'liq grant asosida (Full Tuition + Stipend) bakalavriat, magistratura va PhD bosqichlarida o'qish, nufuzli xalqaro ilmiy konferensiyalarda qatnashish, madaniy-akademik almashinuv dasturlarida ishtirok etish hamda qisqa muddatli yozgi ilmiy amaliyotlarni topish uchun yaratilgan yagona xolis platforma.

Platformada uchinchi tomon vositachilari yoki soxta ma'lumotlar mavjud emas. Barcha 155+ ta'lim dasturlari bevosita rasmiy elchixonalar, xalqaro fondlar (DAAD, Fulbright, Chevening, Erasmus Mundus, MEXT, GKS va boshqalar) hamda dunyo TOP universitetlarining rasmiy qabul portallariga yo'naltirilgan.

---

## ✨ Asosiy Xususiyatlar va Imkoniyatlar

1. **155+ Saralangan Haqiqiy Imkoniyatlar Bazasi:**
   - 🏛️ **Universitet Grantlari (50 ta):** AQSh (Ivy League), Buyuk Britaniya (Oxbridge), Germaniya, Janubiy Koreya, Yaponiya, Kanada, Singapur va boshqa davlatlar OTMlari.
   - 🌐 **Xalqaro Ilmiy Konferensiyalar (35 ta):** To'liq moliyalashtiriladigan yoshlar sammitlari, BMT (UN) anjumanlari va ilmiy simpoziumlar.
   - 🔄 **Almashinuv Dasturlari (35 ta):** Global UGRAD, Erasmus+, SUSI, TechGirls, Humphrey Fellowship va boshqalar.
   - ⏱️ **Qisqa Muddatli Grantlar & Yozgi Maktablar (35 ta):** CERN Summer Student, ETH Zurich, RIKEN, DAAD yozgi til kurslari va laboratoriya tadqiqotlari.

2. **Bir Bosishda Profil Moslashtirish & Kirish Tizimi:**
   - Foydalanuvchi yoshi, ta'lim bosqichi, yo'nalishi va til bilish darajasiga (IELTS / SAT / CEFR) mos dasturlarni bir zumda saralab berish.
   - 1-bosishda tezkor demo profil bilan tizimga kirish yoki shaxsiy profil yaratish imkoniyati.

3. **Bosqichma-bosqich "Ariza Yo'riqnomasi" (Application Roadmap):**
   - Har bir grant kartasida alohida yo'riqnoma: 5 bosqichli harakatlar rejasi, zarur hujjatlar ro'yxati (interaktiv nazorat cheklisti), ekspert maslahatlari va rasmiy manba havolasi.

4. **Sun'iy Intellekt (AI) Mentor:**
   - Motivatsiya xati (Motivation Letter / SOP) va akademik rezyume (CV/Resume) matnini tekshirib, xalqaro standartlar bo'yicha baholash va takliflar berish.

5. **Akademik Mini-kurslar:**
   - Grant yutish sirlari, ATS-mos rezyume yaratish, suhbatdan (Interview) o'tish va professorlardan tavsiyanoma olish bo'yicha qisqa darsliklar.

6. **PWA (Progressive Web App) Imkoniyatlari:**
   - 📱 **Mobil & Desktop Adaptiv:** Har qanday ekran o'lchamiga (smartfon, planshet, noutbuk, katta monitorlar) avtomatik moslashadi.
   - 📲 **O'rnatish Imkoniyati:** Brauzerdan to'g'ridan-to'g'ri telefon yoki kompyuter bosh ekraniga alohida dastur (App) sifatida o'rnatiladi.
   - ⚡ **Oflayn Rejim (Offline Support):** Service Worker texnologiyasi orqali internet aloqasi uzilganda ham katalog va ma'lumotlar bazasi to'laqonli ishlaydi.
   - 🌙 **Ko'zga Yumshoq Dizayn:** Kunduzgi va yumshoq tungi (Soft Dark Mode) rejimlar.

## 🚀 GitHub Pages Orqali Saytni Jonli Ishga Tushirish

1. Ushbu loyihani GitHub omboriga (repository) yuklang.
2. GitHub omboringizda **Settings** bo'limiga kiring.
3. Chap tomondagi menyudan **Pages** bo'limini tanlang.
4. **Branch** qismida `main` (yoki `master`) tanlab, papka sifatida `/ (root)` ni belgilang va **Save** tugmasini bosing.
5. Bir necha daqiqadan so'ng saytingiz xavfsiz HTTPS protokoli orqali barcha uchun ochiq bo'ladi:
   `https://<sizning-username>.github.io/<repo-nomi>/`
